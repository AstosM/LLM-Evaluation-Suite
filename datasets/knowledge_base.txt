
LLM EVALUATION

LLM evaluation is the process of measuring the quality, accuracy, reliability and safety of responses generated by large language models. Automated evaluation frameworks use test datasets and metrics to identify weaknesses in model outputs.

FAITHFULNESS

Faithfulness measures whether an AI-generated answer is supported by the retrieved reference context. A faithful answer should not introduce unsupported facts or contradict the supplied documents.

ANSWER RELEVANCY

Answer relevancy measures how directly an AI response addresses the user's question. An answer can contain correct information but still receive a low relevancy score if it does not answer the actual question.

HALLUCINATION

Hallucination occurs when a language model generates information that is incorrect, fabricated or unsupported by available evidence. Evaluation systems should identify claims that cannot be verified from the reference context.

RETRIEVAL AUGMENTED GENERATION

Retrieval-Augmented Generation, also called RAG, combines information retrieval with language generation. The system first searches a knowledge base for relevant documents. It then provides the retrieved information as context to the language model to generate an answer.

CHROMADB

ChromaDB is a vector database used to store and retrieve document embeddings. It supports similarity search, allowing applications to find documents that are semantically related to a user query.

PROMPT INJECTION

Prompt injection is an attack in which malicious instructions are included in a user prompt or external content to manipulate an AI system. Common examples include attempts to override system instructions or reveal confidential information.

PERSONAL IDENTIFIABLE INFORMATION

Personally Identifiable Information, or PII, includes sensitive information such as email addresses, phone numbers and identification numbers. AI safety systems can use detection and redaction rules to reduce accidental exposure of such information.

ADVERSARIAL TESTING

Adversarial testing evaluates how an AI system behaves when given intentionally harmful, misleading or manipulated inputs. It helps identify security weaknesses and unexpected model behavior.
